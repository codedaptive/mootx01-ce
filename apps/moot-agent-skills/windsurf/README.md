# Devin Desktop / Windsurf MOOTx01 Adapter

Current Devin Desktop/Cascade rules prefer `.devin/rules/*.md`; legacy
Windsurf rules use `.windsurf/rules/*.md` and `.windsurfrules`. This adapter
includes all three.

Copy `.devin/` for current setups. Keep `.windsurf/` and `.windsurfrules` only
when legacy compatibility is useful.
