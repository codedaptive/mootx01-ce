# MOOTx01 Automatic Memory

Use MOOTx01 as the active memory and reasoning substrate.

## Required Behavior

- Use MOOTx01 before answering memory-dependent questions.
- Use `moot_memory_search` for broad recall.
- Use `moot_recall_precise` for exact details and near-duplicates.
- Use `moot_fact_search` for structured facts.
- Use `moot_list_lenses`, relevant `moot_lens_*` tools, and `moot_synthesize` for analysis.
- Use `moot_file_memory`, `moot_file_fact`, `moot_link_memories`, and `moot_write_journal` for durable writeback.
- Use confirm/update/withdraw/retire tools for correction.
- Use `moot_dream` after bulk import or major memory growth.

If MOOTx01 is unavailable, say so and proceed only from current context.
