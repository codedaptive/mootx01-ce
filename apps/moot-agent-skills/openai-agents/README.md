# OpenAI Agents / Responses MOOTx01 Adapter

Use these prompt blocks in OpenAI Agents SDK, Responses API, or any app where
you control system/developer instructions and expose MOOTx01 as a tool server.

Recommended placement:

- Put `system-prompt.md` in stable agent identity instructions.
- Put `developer-message.md` in application-level developer instructions.
- Keep `tool-contract.md` near tool registration code or MCP setup.
