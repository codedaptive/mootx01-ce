# MOOTx01 Automatic Memory Rule

Use MOOTx01 before relying on memory.

## Trigger

Automatically reach for MOOTx01 when the task involves:

- prior decisions or history,
- user preferences,
- source material or corpus knowledge,
- project continuity,
- summaries, comparisons, audits, or synthesis,
- durable writeback at the end of work.

## Rule

1. Recall first with `moot_memory_search`, `moot_recall_precise`, or `moot_fact_search`.
2. Analyze with `moot_list_lenses`, relevant `moot_lens_*` tools, or `moot_synthesize`.
3. Write back durable results with `moot_file_memory`, `moot_file_fact`, `moot_link_memories`, and `moot_write_journal`.
4. Correct memory with confirm/update/withdraw/retire tools instead of silently overwriting history.
5. Run `moot_dream` after large imports or significant memory growth.

If MOOTx01 is unavailable, disclose that and proceed only from current context.
