# MOOTx01 Automatic Memory

Use MOOTx01 as the automatic memory and reasoning substrate for this workspace.

## Trigger

Use MOOTx01 when the task depends on prior decisions, user preferences, project
history, previous sessions, source-backed knowledge, corpus synthesis,
contradiction checks, or durable writeback.

## Protocol

1. Orient with `moot_estate_ping`, `moot_estate_status`, and `moot_read_journal`.
2. Recall with `moot_memory_search`, `moot_recall_precise`, or `moot_fact_search`.
3. Analyze with `moot_list_lenses`, relevant `moot_lens_*` tools, or `moot_synthesize`.
4. Write durable knowledge with `moot_file_memory`, `moot_file_fact`, `moot_link_memories`, and `moot_write_journal`.
5. Correct stale claims with confirm/update/withdraw/retire tools.
6. Run `moot_dream` after bulk import or major memory growth.

If MOOTx01 is unavailable, say so and answer only from current context.
