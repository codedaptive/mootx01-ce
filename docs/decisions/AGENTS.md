# Decisions — Why It Was Built This Way

Architecture decision records and rulings: the question, the candidates, the
evidence, and what was chosen. A decision record is written once and then
superseded rather than edited, so a reader can see what was believed at the
time.

A record lives here while it is IN FORCE, and moves to `archive/decisions/` when
nothing cites it any more. Release era is not the rule — several 1.0-era
rulings govern the current line, and several written for this line are quoted
nowhere. An archived record that live material still cites is a broken
reference, which `check-decisions-in-force.py` catches.

This directory publishes. A ruling in force that the Community edition does not
carry goes in `internal/decisions/` — being in force and being public are
separate questions.
