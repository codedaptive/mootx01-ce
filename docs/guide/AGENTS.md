# Guide — Using The Product

User-facing documentation: what someone does with the product, in their words
rather than the system's. Written after behaviour ships, from the shipped
behaviour, not from the plan.

Implementation guidance belongs in `engineering/`, the conceptual model in
`concepts/`. If a passage only makes sense to someone who has read the source,
it is not a guide passage.

This directory publishes. Mission-specific guide deltas are maintainer material
and live in `internal/guide/deltas/`.
