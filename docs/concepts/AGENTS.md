# Concepts — What The System Is

The conceptual model: what a drawer, a tunnel, a lens and an estate are, how
memory is shaped, why the design works the way it does. A reader here is
building a mental model, not implementing against an interface.

An API surface belongs in `reference/`, a ruling in `decisions/`, a how-to in
`engineering/`. A concepts document that starts listing method signatures has
become a reference document.

This directory publishes. Everything in it reaches the Community edition, so a
note that must stay private goes in `internal/concepts/` instead.
