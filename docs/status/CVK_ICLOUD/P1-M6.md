# CVK-ICLOUD P1-M6 — Completion Report

**Status:** COMPLETE

## What Was Done

### Part 1 — CKErrorTaxonomy.swift (new file)
Classifies every known `CKError.Code` into four transport-response postures:
`retryableBackoff`, `reclaim` (zone or token invalid), `conflict`
(serverRecordChanged), and `permanent` (quota, size, config). Non-CKError
types (URLError) classify as retryableBackoff. `@unknown default` catches
future SDK additions. `ReclaimKind` and `PermanentReason` carry Sendable
conformance.

Note: `CKError.Code.virusScanFailed` and `.encryptionMismatch` were removed
— they do not exist on the installed SDK version. The `@unknown default` case
covers them in future SDK versions.

Committed in: `57a5e48a` (blast radius report) — source changes to follow commit.

### Part 2 — RetryPolicy.swift (new file)
Deterministic exponential backoff: `baseDelay × 2^attempt`, capped at
`maxDelay`, with signed jitter (±jitterFraction). Server-suggested delay
from `CKError.retryAfterSeconds` is a hard floor. Exponent capped at 30 to
prevent overflow on very high retry counts. Fully injectable (clock/RNG) for
deterministic tests.

### Part 3 — PushResults.swift (new file)
Pure function `PushResults.process(saveResults:recordToEntryID:classifyError:)`.
Returns `PushOutcome` with `confirmedIDs`, `retryIDs`, `parkedIDs`, and
`reclaimNeeded`. No CloudKit operations inside; testable with synthetic
result dictionaries. The `classifyError` parameter defaults to
`CKErrorClass.classify(_:)` and is injectable in tests.

## Discoveries

- `CKError.Code.virusScanFailed` and `.encryptionMismatch` do not exist on
  the installed SDK. The classification switch covers them implicitly via
  `@unknown default → retryableBackoff`. This is the correct conservative
  behavior: if these codes ever appear, retrying is safer than parking.
- The P1-M3 parallel mission (CloudKitDatabaseProtocol seam) was not included.
  Per mission instructions, transport injection was tested at the smallest
  available boundary: the `classifyError` closure in `PushResults.process`
  (pure function injection, no seam needed).

## Outstanding

- `is_parked` column name uses `isParkDecl` in the schema constant — trivial
  naming inconsistency, no functional impact.
- `RetryPolicy` is constructed but not stored on `CloudKitStateActor`; the
  actual scheduling of the delay between push cycles remains the caller's
  responsibility. RetryPolicy provides the computation; the actor provides
  the timing. Wiring the delay into the auto-push scheduling loop is
  P4-M1 scope.
