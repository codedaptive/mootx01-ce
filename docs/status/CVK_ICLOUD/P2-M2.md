## Discoveries

- **Full-row observer semantics require `isStormKill` not `isAllExcluded`**:
  InMemory and SQLite storage backends emit the FULL merged row in
  `TableChange.values` for update events. This means `isAllExcluded` (which
  checks if every key is excluded) can never return `true` when the PK is
  present and not excluded. The correct storm-kill predicate is
  `isStormKill(stripped:primaryKeyColumn:)`: after stripping, if only the PK
  remains, the update touched only excluded columns. `isAllExcluded` is kept
  for semantic completeness and covers theoretical schemas where the full row
  consists only of excluded columns.

- **OSLog file-private scope**: `CloudKitStateActor.swift` declares
  `private let logger` — file-private in Swift, inaccessible to extensions in
  `ApplyInbound.swift`. Pattern: file-local logger with same subsystem/category.

- **Sibling missions P2-M1 and P2-M3 also touch SyncTypes.swift**: this mission
  added `excludedColumns` only; root reconciles all three P2 changes at merge.
