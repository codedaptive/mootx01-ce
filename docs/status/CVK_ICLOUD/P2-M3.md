## Discoveries

- `invokeIntegrityHook` needs `package` access (not `internal`) because
  `ConvergenceKitFederation` and `ConvergenceKitCloudKit` are separate modules
  that import `ConvergenceKit`; `internal` does not cross module boundaries in
  the same package. `package` access (Swift 5.9+) is the correct scope.
- The worktree is based on `cec028eb` (before P1 CVK-ICLOUD work), not on
  P1-complete `b35ed242`. This means FederationSyncEngine has no echo
  suppression (A6) and CloudKitSyncEngine has no Engine/ subdirectory split.
  The hook was implemented on the old code; root will reconcile P1+P2 overlaps.
- `SyncManifest` tests in conformance suite tested JSON encoding of the manifest.
  These were replaced with `SyncedTable`-level JSON tests (SyncedTable IS
  Codable and IS the wire-relevant nested type). The wire format for manifests
  was never sent over the wire anyway — only `SyncRecord` is the wire format.
- R3-2 (hook-writes-must-ship) is slightly sensitive to parallel test execution
  timing. Added a 200ms explicit sleep before `pushUntilNonzero(engineB)` to
  give the storage observer Task time to enqueue the hook write before the first
  push attempt — mirrors the pattern in FederationStubTests (100ms sleep before push).
