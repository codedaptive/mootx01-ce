## Claims NOT fully verifiable in source

**N2 — "16 slots" vs "1...0x0F" (15 usable values):**
The mission specifies a "registry of 16 well-known records" and "16
SIMULTANEOUSLY ACTIVE machines." The source at line 108 generates
`Int32.random(in: 1...0x0F)` — that is 15 values (1 through 15),
skipping node 0. The mission's own text says p≈1/15, consistent with
15 usable choices. Whether the registry design allocates all 16 node
values (0–15) or 15 (1–15) is not resolved by the current source; the
current code skips 0. The decision doc follows the mission's approved
language ("16 well-known records", "16 simultaneously active
machines"). This tension is noted for the implementation mission to
resolve — specifically whether node 0 participates in the registry.

accelerator, not yet implemented). No inconsistency — N3 is a
requirement, not a claim about current code.
