## Discoveries

- **StorageRow vs dict**: `rowStore.query()` returns `[StorageRow]`, not
  `[[String: TypedValue]]`. `StorageRow` wraps `.values: [String: TypedValue]`
  and provides a subscript. Decode functions that receive query results must
  accept `StorageRow` or unwrap `.values`. Mission code now passes `row.values`.
- **Swift 6 ISO8601DateFormatter**: `ISO8601DateFormatter` is not `Sendable`
  per the SDK header, but the documentation confirms it's thread-safe once
  configured. `nonisolated(unsafe)` is the correct annotation for a
  configured-once static property of a non-Sendable class.
- **Public struct memberwise init**: Swift synthesises `internal` memberwise
  init for `public struct`. Any `public struct` that is constructed in test
  targets (cross-module) needs an explicit `public init`. Added to `DeviceIdentity`.
- **Worktree INTERFACE version**: the worktree's INTERFACE doc was at v1.0.0
  (develop/1.1.x is at v1.3-draft); the worktree fork diverged before those
  draft changes landed. Updated the worktree copy to v1.1 with the P1-M2
  changes applied. The full v1.2/v1.3 content will land when P1-M3 merges.
- **Test count baseline drift**: main develop/1.1.x had 72 tests at the time the
  worktree was cut; the worktree started at 71. Used 71 as the floor.
