## Teardown-Race Test Description

`teardownRaceNoTriggerAfterCancel()`: arms debouncer with a 5 ms coalescing window,
then immediately calls `cancel()` without yielding. Even if the 5 ms sleep completed
before `cancel()` runs, the generation counter (`&+= 1` before `await t?.value`) ensures
`fireTrigger()` finds a stale token and returns without calling the trigger. The `await t?.value`
in `cancel()` drains any in-flight trigger invocation before returning, making the guarantee
deterministic and not timing-dependent.
