## Mechanical Changes (not logic)

- Four methods promoted from `private` to internal to enable cross-file actor extension access:
  `emit`, `nowMillis`, `readSyncHLC`, `writeSyncHLC`
- `private static let syncMetaTable` stays private — all uses remain in SyncMetaStore.swift
- `private let logger` (was module-level in CloudKitSyncEngine.swift) redeclared as `private let`
  in each file that uses it (CloudKitStateActor.swift, PushCycle.swift, PullCycle.swift).
  Same subsystem+category — identical runtime behavior.
- CloudKitSyncEngine.swift file header updated to reference the Engine/ layout per comment-fidelity rule.
  The DO NOT REIMPLEMENT SUBSTRATE MATH banner moved to CloudKitStateActor.swift (the file that imports
  SubstrateTypes and owns HLCGenerator).
