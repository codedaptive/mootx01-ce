# CVK-ICLOUD P1-M8 — Hygiene: Remove Synthetic PushCompleted Start Signal

**Status:** COMPLETE

## What Was Done

Deleted the synthetic `pushCompleted(receipt: SyncReceipt.empty)` emission and its "start signal; reset after work" comment from `PushCycle.swift:push()` (line 24). This signal was causing subscribers to observe every push completing twice: once with an empty receipt at the start, then again with the actual receipt at the end.

Added test `pushDoesNotEmitSyntheticStartSignal()` to `CloudKitStubTests.swift` asserting that the push cycle no longer emits spurious start events.
