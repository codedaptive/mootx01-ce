## Summary

NeuronKit's first symbolic-discovery reasoning function. A pure,
deterministic pairwise association-rule mining engine now lifts
single-antecedent → single-consequent rules off the co-occurrence
matrix `MatrixO`: matrix + injected active row count + thresholds in,
ranked `[AssociationRule]` out, with all five standard metrics
(support, confidence, lift, conviction, leverage). Both legs (Swift +
Rust) run identical math against identical in-code hand-computed
vectors, mirroring the `MMRRank` pure-engine + inline-conformance
pattern. Tier: net-new (no cap); the only edit to existing code is the
single sanctioned `pub mod association_rule_mining;` registration line
in `rust/src/lib.rs`.

Mission-mandated contract points, implemented and tested:
- **Single-item support from `MatrixO`'s retained diagonal** (`O[A,A]`),
  not `MatrixF` (which counts per-bit presence — wrong denominator).
- **Diagonal excluded from rule emission** (an `A → A` self-rule has
  confidence ≡ 1 and carries no information).
- **`N` injected, never derived**; `N <= 0` → `[]`.
- **Emission order fully specified**: ascending packed
  `(antecedent, consequent)` key — which is exactly `MatrixO.entries`'
  canonical order, so the ordered scan needs no explicit sort and the
  Swift/Rust emission order is identical by construction.
- **`conviction = +inf` at `confidence == 1`**, exact-division case.
- Edge guards: `O[A,A] == 0` skips the antecedent, `O[B,B] == 0` skips
  the consequent, below-threshold rules dropped.
