# Assets — Images And Diagrams For The Published Documentation

Diagrams, screenshots and media referenced by the documents that publish. An
asset here is part of the published documentation and travels with it.

Keep them referenced. An asset nothing links to is weight in every clone, and
the media here is large — the start-here set is tens of megabytes and is stored
through Git LFS, so it commits as a pointer rather than as bytes. If that ever
lands as raw blobs, the stage is missing its LFS filter.

Evidence captures from a verification run are not assets; they are records, and
they belong in the maintainer tree.
