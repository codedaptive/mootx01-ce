# Start Here — The First Thing A Reader Opens

Orientation for someone arriving with no context: what the product is, how to
install it, where to go next. Written for a reader who does not yet know the
vocabulary, which is what distinguishes it from `concepts/`.

Keep the path short. Every document added here competes with the one a newcomer
actually needs, and the failure mode is a start-here directory nobody can start
in.

The media under `ai-memory-assets/` is stored through Git LFS and is large. It
publishes as pointers, not bytes.
