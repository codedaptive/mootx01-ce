# AI Knowledge for Legacy Lane Documents

This directory documents the original end-to-end internal lanes. The canonical
release 1.1 definitions are under `../docs/benchmarks/`; when statements
overlap, those definitions and the run book control.

Keep lane data seed-deterministic, bulk-imported, settled before measurement,
and scored mechanically. Every result names its seed, port, estate posture,
estate state, recall shape, coverage, binary identity, and any judge identity.
Raw output belongs under `$BENCH_WORK_ROOT/results`; accepted figures belong in
the applicable `../results/` page.
