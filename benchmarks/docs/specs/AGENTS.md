# Official Protocol Extraction Knowledge

These files are the release 1.1 source-protocol contracts for the five spec
lanes:

- `LONGMEMEVAL_OFFICIAL_PROTOCOL.md` -> `lme-spec`
- `LOCOMO_OFFICIAL_PROTOCOL.md` -> `locomo-spec`
- `LMEB_CONVOMEM_OFFICIAL_PROTOCOL.md` -> `lmeb-spec` and `convomem-spec`
- `MEMBENCH_OFFICIAL_PROTOCOL.md` -> `membench-spec`

Preserve verbatim prompts, normalization, judge parameters, candidate
restriction, metric equations, aggregation, and capacity semantics. Clearly
separate upstream protocol text from the local lane mapping. A local deviation
must be explicit and must not be reported as upstream-equivalent.

Do not add measured values, implementation progress, or historical repair
narratives. Operator commands live in `../BENCHMARK_RUN_BOOK.md`; benchmark
identity and provenance live in `../BENCHMARKS_USED.md`.
